# JanaSabha — AI-Powered Public Petition Platform (POC)

A proof-of-concept application that lets Kerala citizens submit petitions to their elected representatives using voice input in Malayalam or English.

## What it does

**Citizen flow**
1. Speak your problem or request in Malayalam or English
2. See the transcript of what was heard
3. Get a formal, well-structured petition generated by AI
4. Hear the petition read back aloud (for accessibility)
5. Edit manually or speak a correction — draft updates accordingly
6. Submit the petition to your elected representative

**Member dashboard**
- View all submitted petitions, auto-categorized (Roads, Water, Health, etc.)
- Filter by category and status
- Expand any petition to see the original speech and the formal text
- Update petition status (New → Acknowledged → In Progress → Resolved)

## Tech stack

| Layer | Tool |
|---|---|
| Frontend + API routes | Next.js 15 (App Router) |
| Database | SQLite via `better-sqlite3` |
| Speech-to-Text | OpenAI Whisper API |
| Petition draft generation | OpenAI GPT-4o |
| Text-to-Speech | OpenAI TTS API |

## Getting started

### 1. Clone and install

```bash
git clone <repo-url>
cd janasabha
npm install
```

### 2. Add your OpenAI API key

```bash
cp .env.example .env.local
# Edit .env.local and add your key:
# OPENAI_API_KEY=sk-...
```

Get an API key at [platform.openai.com](https://platform.openai.com). Add ~$5 credits — enough for hundreds of petition drafts during testing.

### 3. Run the app

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the citizen page.
Open [http://localhost:3000/dashboard](http://localhost:3000/dashboard) for the member dashboard.

## POC iterations

- **Iteration 1** — Record audio → transcribe (Whisper)
- **Iteration 2** — Transcript → formal petition draft (GPT-4o)
- **Iteration 3** — Read draft aloud (OpenAI TTS)
- **Iteration 4** — Voice/text corrections → updated draft
- **Iteration 5** — Submit petition → member dashboard with categorization

## Notes

This is a POC — no authentication, no production optimizations. The OpenAI Whisper `language: 'ml'` parameter improves Malayalam transcription accuracy. For the final product, replace OpenAI APIs with self-hosted open-source models (AI4Bharat Indic Whisper, Llama 3.1, IndicTTS).
